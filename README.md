# Функциональное назначение программы

Конвертирование png/jpg-изображений в текстовый формат с использованием ASCII-символов.

# Демонстрация работы

![Демонстрация Snake](screenshots/демонстрация.jpg)

# Сборка и запуск

* Склонируйте или скачайте репозиторий.
* В IDE, поддерживающую python, активируйте виртуальное окружение с помощью команды

      ASCII-image\.venv\Scripts\activate.bat
* Запустите программу с помощью команды
  
      python main.py
